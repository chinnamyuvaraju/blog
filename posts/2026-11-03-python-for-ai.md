Pick a question you can answer with a table of examples. Could you predict how many bikes a station will need on a weekday morning? Start with a few useful inputs, such as the hour, day of the week, and weather.

- Use **pandas** to inspect the table and handle missing values.
- Use **NumPy** when you need to work with numerical arrays.
- Start with a baseline, such as the station's usual weekday demand. Try a simple model and test it on a later week the model hasn't seen.
- Explore **PyTorch** when you're ready to train a neural network and have a reason to compare it with the simpler approach.

Write down where the model made its biggest mistakes. That is usually where the next project begins.
